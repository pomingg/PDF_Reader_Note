# PDF 閱讀筆記

在自己電腦上使用的 PDF 閱讀器：依專案／資料夾整理 PDF，畫重點、寫備註與標籤，筆記可以匯出成 Markdown，也能和 Acrobat、iPad 等其他 PDF 軟體互通。所有資料都只存在你的電腦上。

## 安裝

需要：

- [Node.js](https://nodejs.org/) **22.13 以上**（建議安裝 24 LTS）。不需要 Visual Studio 或其他編譯工具。
- [Git](https://git-scm.com/)（Windows 安裝時全部用預設值即可）

在終端機（Windows：命令提示字元或 PowerShell；Mac：終端機）執行：

```bash
git clone https://github.com/pomingg/PDF_Reader_Note.git
cd PDF_Reader_Note
npm install
npm run dev
```

看到 `Ready` 後，用瀏覽器打開 <http://localhost:3000>。要關閉時在終端機按 `Ctrl + C`。

日常使用建議用正式模式，速度較快：

```bash
npm run build
npm start
```

> 使用 Node 22 時，啟動會出現一行 `ExperimentalWarning: SQLite is an experimental feature`，可以忽略；Node 24 不會出現。

### 更新到最新版

```bash
git pull
npm install
```

更新不會動到你的資料（都在 `data/` 資料夾）。

## 功能

### 整理文件

- **專案與資料夾**：左側「專案 ＋」新增專案，在專案或資料夾的「⋯」選單新增子資料夾。系統內建「未分類」
- **加入 PDF** 有兩種方式：
  - **上傳**：按「上傳 PDF」或把檔案拖進頁面，會複製一份到程式的資料夾
  - **連結電腦資料夾**：在專案頁按「📂 連結電腦資料夾」，選擇電腦上的資料夾，裡面的 PDF（含子資料夾）會**直接開啟原檔，不複製**
    - 資料夾裡新增的 PDF 會自動加入；被修改的檔案（例如在 Acrobat 畫了重點）會自動重新匯入註解
    - 檔案改名或搬到同一個連結資料夾的其他位置，筆記會跟著走；找不到的檔案會標示「找不到檔案」，可用「⋯ → 重新指定檔案位置」指回去
    - 在程式裡移除連結的文件**不會刪除電腦裡的檔案**
    - 已連結的資料夾可在「💾 匯出與備份」頁管理
- **移動**：把文件或資料夾拖到左側樹狀目錄，或用文件的「⋯ → 移動到…」
- **搜尋**：專案頁可搜尋文件名稱，可只搜目前專案或全部

### 閱讀

- 目錄、縮圖、全文搜尋、書籤四個側欄分頁
- **顯示方式**（工具列的「☰ 連續」按鈕）：連續捲動、單頁、雙頁並排
- 縮放：符合寬度、符合頁面、自訂比例；每份文件會記住上次的顯示方式、縮放與讀到的頁數
- **書籤**：工具列的 🏷 或按 `B`，可命名，在「書籤」分頁點一下就跳過去
- **夜間閱讀**：顯示方式選單裡，把 PDF 頁面變成深底淺字
- **外觀**：左下角可切換淺色、深色或跟隨系統
- **全螢幕**：按 `F`

### 畫重點與筆記

- 選取文字後會出現工具列，點顏色畫重點；也可以按 `1`–`4` 上色，按 `N` 畫重點並寫備註
- 顏色意義預設為 黃＝重點、紅＝疑問、綠＝定義、藍＝例子，可在筆記側欄的 ⚙ 修改
- 「⬚ 框選」（或按 `A`）框出圖表、公式等選不到字的區域，存成截圖
- 筆記側欄可依顏色、類型、標籤篩選；點筆記會跳到原文並閃爍
- 備註支援 Markdown 與 LaTeX 公式（`$E=mc^2$`、`$$...$$`），自動儲存
- 「＋ 筆記」可新增此頁筆記或整份文件筆記

### 和其他 PDF 軟體互通

- **匯入**：Acrobat、Edge、Mac 預覽程式、GoodNotes、PDF Expert 等軟體存在 PDF 裡的螢光筆、底線、便利貼、文字方塊、手寫，會在第一次開啟時自動匯入成筆記（筆記側欄的「⤓」可手動重新匯入）
- **更新 PDF 檔**（上傳的文件）：文件「⋯ → 更新 PDF 檔」換上新版本，筆記保留並匯入新的註解
- **寫回**：閱讀器「⬇ → 下載含重點的 PDF」，把這裡的重點與備註寫成標準 PDF 註解，任何 PDF 軟體都看得到

### 匯出與備份

- **匯出 Markdown**：每份文件一個 `.md`（含原文引用、頁碼、備註、標籤、書籤、框選截圖），依專案／資料夾分層，可直接放進 Obsidian
  - 單一文件：閱讀器「⬇」；專案或資料夾：該頁的「⬇ 匯出筆記」；全部：「💾 匯出與備份」
- **完整備份**：「💾 匯出與備份」→「下載完整備份」（所有資料＋上傳的 PDF＋截圖；連結的 PDF 留在原位，不會打包）
- **還原**：同一頁上傳備份檔，會取代目前所有資料；還原前會自動把現有資料另存到 `data/backups/`

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `←` / `→` | 上一頁／下一頁（雙頁模式一次兩頁） |
| `PageUp` / `PageDown` | 翻頁（單頁、雙頁模式） |
| `Home` / `End` | 第一頁／最後一頁 |
| `Ctrl/⌘ + F` | 全文搜尋 |
| `Ctrl/⌘ + +` / `−` / `0` | 放大／縮小／符合寬度 |
| `B` | 目前頁加入／移除書籤 |
| `F` | 全螢幕 |
| `A` | 框選模式 |
| 選取文字後 `1`–`4` | 用對應顏色畫重點 |
| 選取文字後 `N` | 畫重點並寫備註 |
| `Esc` | 取消框選／取消選取 |
| `?` | 顯示快捷鍵說明 |

## 資料存放

所有資料都在專案內的 `data/` 資料夾（不會進 git）：

```
data/
  app.db      # SQLite 資料庫：專案、資料夾、文件、筆記、標籤、書籤、設定
  pdfs/       # 上傳的 PDF（連結的 PDF 留在你電腦原本的位置）
  snapshots/  # 框選擷取的圖片
  backups/    # 還原前自動保存的備份（可自行刪除舊的）
```

想把資料放在其他位置（例如雲端硬碟的同步資料夾），啟動前設定環境變數 `PDF_NOTES_DATA_DIR`：

```bash
PDF_NOTES_DATA_DIR=/path/to/my-data npm start
```

> 安全性：程式只在本機（`localhost`）提供服務，同網路的其他裝置連不進來。

## 技術架構

- Next.js 16（App Router）＋ React 19 ＋ Tailwind CSS 4
- pdf.js（`pdfjs-dist`）渲染 PDF 與文字層；CMap 與標準字型由 `public/pdfjs/` 提供（`npm install` 時自動複製），中文 PDF 正確顯示；頁面對齊實體像素，縮放時保持清晰
- SQLite：Node 內建的 `node:sqlite`，安裝時不需要編譯原生套件
- 筆記以 Markdown 儲存，用 `react-markdown` ＋ KaTeX 顯示；`pdf-lib` 寫回 PDF 註解；`fflate` 處理 zip
- 每個重點同時記錄頁面上的相對座標（0–1，不受縮放影響）與原文文字＋前後文

```
app/(library)/       首頁、文件庫、匯出與備份頁（含側邊欄）
app/read/[id]/       閱讀器
app/api/             projects / folders / documents / annotations / bookmarks / linked-folders / export / backup API
components/reader/   閱讀器元件（頁面渲染、重點圖層、選取工具列、筆記側欄、目錄、縮圖、搜尋、書籤）
lib/db.ts            資料庫連線、資料表與自動升級
lib/library.ts       專案／資料夾／文件
lib/linked.ts        連結電腦資料夾、掃描與資料夾瀏覽
lib/notes.ts         筆記、標籤、顏色設定、PDF 註解匯入
lib/bookmarks.ts     書籤
lib/export.ts        Markdown 匯出、完整備份與還原
lib/pdfWrite.ts      把筆記寫回 PDF
```
